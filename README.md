# breast-cancer-classification
Machine learning classification project using the Breast Cancer Wisconsin dataset.
## Project Overview

This project uses the Breast Cancer Wisconsin dataset to build a machine learning classification model for predicting whether a breast tumor is benign or malignant.

## Dataset

The Breast Cancer Wisconsin dataset contains measurements related to breast tumor characteristics.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning

A classification model was developed and evaluated using training and testing data.

## Results

- Training Accuracy: 97.50%
- Testing Accuracy: 95.00%
- Precision: 93.62%
- Recall: 91.67%
- F1 Score: 92.64%

## Conclusion

The model achieved good performance in classifying breast tumors. The project demonstrates how data science and machine learning can be applied to a healthcare-related dataset.
